# 台股大冒險（原型）

L.P.L.C.-System 的第一個視覺化模組，用 16 位元 RPG 的世界地圖看「錢今天流到哪裡」。目前使用 **mock 行情**，
資料層已抽象化，之後可以直接換成富果或證交所資料。

## 畫面

網站分兩頁，從頂部的分頁按鈕切換，網址 `#map`、`#intel` 可以直接開到指定頁：

- **世界地圖**（預設）：整頁只放地圖與對話框。點領地或王國，右上角會浮出狀態視窗。
- **冒險情報**：王國一覽、大盤走勢、資金輪動、資金流排行、細節與冒險日誌。

播放速度、暫停 / 重播與漲跌配色收在右上角的「選單」裡。

| 區塊 | 讀法 |
|---|---|
| **世界地圖**（中央） | 每個產業是一個王國，有自己的像素地形圖示（半導體山脈、金融王城、航運港⋯）；每檔股票是一塊領地。地圖切成 8×8 像素的方格，每一格代表相同的成交額，所以領地大小 = 今日成交額。地面顏色 = 漲跌；成交低於常態（資金撤出）的領地蓋上暗色網點；吸金最強的 6 檔頭上有金幣跳動；盤中被別的領地奪下的格子會閃白光；王國邊界是金色虛線。 |
| **對話框**（地圖下方） | 盤中事件用 RPG 對話框逐字打出來，點一下會選取事件提到的股票或產業。 |
| **冒險日誌**（情報頁） | 所有事件：產業資金轉向、資金龍頭易主、資金流每突破 50 億、個股漲跌超過 5% 或觸及漲跌停、大盤漲跌突破整數百分比。 |
| **資金輪動**（情報頁） | 每列一個產業、每格 5 分鐘，顏色 = 該時段成交佔比偏離常態的百分點。 |

點王國或領地會在地圖與面板同步標示（游標指著選取的領地），Esc 取消選取。

## 定義

| 項目 | 定義 |
|---|---|
| 成交佔比 | 個股今日成交額 ÷ 今日總成交額 |
| 常態 | 近 20 日平均成交額的佔比 |
| 資金流 | （成交佔比 − 常態）× 今日總成交額；所有個股加總為 0 |
| 領地格數 | 成交佔比 × 總格數（每格 = 今日總成交額 ÷ 總格數） |

## 開發

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # 資金流、地圖方格、輪動、事件偵測、模擬行情測試
npm run build      # 型別檢查 + 打包到 dist/
```

## 結構

```
src/
  data/       資料層：型別、MarketDataProvider 介面、mock 股票池與模擬行情
  domain/     資金流（metrics.ts）、資金輪動（rotation.ts）、事件偵測（events.ts）
  layout/     地圖方格與領地分配（tilegrid.ts）
  ui/         世界地圖（canvas）、像素圖示、對話框、輪動條碼與各資訊面板
  main.ts     組裝：provider → metrics → views / panels
```

接真實資料時，實作 `src/data/provider.ts` 的 `MarketDataProvider`，
把行情轉成 `src/data/types.ts` 的格式即可，UI 與領域邏輯不需要修改。
