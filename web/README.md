# L.P.L.C. 資金熱力圖（原型）

L.P.L.C.-System 的第一個視覺化模組，用來看「錢今天流到哪裡」。目前使用 **mock 行情**，
資料層已抽象化，之後可以直接換成富果或證交所資料。

## 視圖

| 視圖 | 讀法 |
|---|---|
| **資金呼吸圖**（主畫面） | 方塊面積 = 今日成交額，虛線框 = 20 日平均規模，顏色 = 漲跌。方塊撐破虛線框代表資金湧入，縮在斜線空地裡代表資金撤出。格位用 resquarify 排列，盤中只會漲縮、不會跳位。 |
| **資金引力場**（第二分頁） | 泡泡面積 = 今日成交額，同產業聚在同一個方位；資金流入越多越靠近中央，流出越多越靠外圈。 |
| **資金輪動條碼**（底部） | 每列一個產業、每格 5 分鐘，顏色 = 該時段成交佔比偏離常態的百分點，看得出盤中輪動。 |

點產業或股票會在所有視圖與右側面板同步標示，Esc 取消選取。

## 定義

| 項目 | 定義 |
|---|---|
| 成交佔比 | 個股今日成交額 ÷ 今日總成交額 |
| 常態 | 近 20 日平均成交額的佔比 |
| 資金流 | （成交佔比 − 常態）× 今日總成交額；所有個股加總為 0 |
| 呼吸圖格位 | max(成交佔比, 常態)；實心方塊 = 成交佔比，虛線框 = 常態 |

## 開發

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # 資金流、呼吸圖格位、輪動、模擬行情測試
npm run build      # 型別檢查 + 打包到 dist/
```

## 結構

```
src/
  data/       資料層：型別、MarketDataProvider 介面、mock 股票池與模擬行情
  domain/     資金流（metrics.ts）、呼吸圖格位（breath.ts）、資金輪動（rotation.ts），純函式
  ui/         呼吸圖、引力場、輪動條碼與各資訊面板
  main.ts     組裝：provider → metrics → views / panels
```

接真實資料時，實作 `src/data/provider.ts` 的 `MarketDataProvider`，
把行情轉成 `src/data/types.ts` 的格式即可，UI 與領域邏輯不需要修改。
