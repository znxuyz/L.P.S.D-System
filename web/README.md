# L.P.L.C. 資金熱力圖（原型）

L.P.L.C.-System 的第一個視覺化模組，用熱力圖看「錢今天流到哪裡」。介面是玻璃數據艙風格：
深空背景、緩慢流動的極光、霧面玻璃面板與漸層描邊；紅綠只用於漲跌。預設使用 **模擬行情**，
在右上角選單可以切換成 **富果** 或 **證交所** 的真實行情（見下方〈使用真實行情〉）。

## 畫面

網站分四頁，從頂部切換，網址 `#map`、`#intel`、`#screen`、`#etf` 可以直接開到指定頁：

- **熱力圖**（預設）：整頁只放熱力圖。點個股或產業標題，右上角浮出細節卡；盤中事件從左下角滑入通知。
- **市場情報**：產業列表、加權指數與台指期走勢、資金輪動、產業與個股資金流排行、細節與盤中事件紀錄。
  台指期顯示近月合約（每月第三個星期三結算後換月）的價格、漲跌、價差（期貨 − 加權，正價差 / 逆價差）與成交口數，
  走勢線和加權指數畫在同一張圖。模擬模式為示意行情；真實行情需要富果金鑰（用富果期貨行情，每 30 秒更新），
  富果方案沒有開放期貨時，選單的狀態會註明。證交所模式沒有期貨資料。
- **五大選股**：五種核心選股策略的條件、通過情況與篩選結果，可以一鍵在熱力圖上只亮出符合的股票。只篩個股。
- **ETF**：市值型、高股息、主題型、主動式、債券型 ETF 的殖利率、配息、折溢價、規模、內扣費用、成分股與成分股變化，可以一鍵在熱力圖上亮出某檔 ETF 的成分股或異動股。

播放速度、暫停 / 重播與漲跌配色收在右上角的設定選單裡。

| 區塊 | 讀法 |
|---|---|
| **熱力圖** | 方塊面積 = 今日成交額，顏色 = 漲跌幅，依產業分組。版面用 resquarify 排列，成交額變化時方塊平滑漲縮、不會跳位。吸金最強的 6 檔內部有呼吸光；成交低於 20 日常態（資金撤出）的方塊降低飽和度；夠大的方塊會畫出盤中股價走勢線。 |
| **盤中事件** | 產業資金轉向、資金龍頭易主、資金流每突破 50 億、個股漲跌超過 5% 或觸及漲跌停、大盤漲跌突破整數百分比。 |
| **資金輪動** | 每列一個產業、每格 5 分鐘，顏色 = 該時段成交佔比偏離常態的百分點。 |

點產業或個股會在熱力圖與面板同步標示，Esc 取消選取。

## ETF

ETF 獨立成一頁，不放進五大選股（ETF 沒有本益比、EPS 等個股指標，風險層級也不同）。
ETF 的成交額**不計入**熱力圖的資金流總額，避免和成分股重複計算；改看「成分股資金流」（列出的成分股今日資金流加總）判斷 ETF 背後的資金方向。

| 指標 | 定義 |
|---|---|
| 殖利率 | 近一年配息 ÷ 現價 |
| 折溢價 | 現價 ÷ 預估淨值 − 1（溢價超過 0.3% 以黃色標示） |
| 成分股加權漲跌 | 列出的成分股漲跌幅依權重加權 |

### 成分股變化

- **被動式（指數型）**：顯示調整頻率、最近一次與下次預計的調整日，以及那次的新進、出清、加碼、減碼與權重變化。
- **主動式**：經理人自行選股、每日公告持股，顯示近 5 個交易日的每日持股異動。
- **主動式 ETF 共識**：統計同一檔股票在近 5 個交易日被幾檔主動式 ETF 加碼（含新進）或減碼（含出清），依淨加碼數排序。

### 主動式 ETF 的真實持股

GitHub Actions 每個交易日台北時間 18:37（22:07 再補抓一次）到投信官網抓主動式 ETF 的每日持股，
和前一個交易日比對算出新進、出清、加碼、減碼，存在 repo 的 `data` 分支，部署時一起放進網站（`data/active-etf.json`）。

| ETF | 投信 | 狀態 |
|---|---|---|
| 00980A 主動野村臺灣優選 | 野村投信 | 已接上 |
| 00981A 主動統一台股增長 | 統一投信 | 已接上 |
| 00982A 主動群益台灣強棒 | 群益投信 | 已接上 |
| 00984A 主動安聯台灣高息 | 安聯投信 | 尚未接上（仍為模擬） |

- 有真實資料的區塊會標示綠色「○○投信公告 MM/DD」，模擬的標示黃色「模擬」。
- 異動要比對兩個交易日，所以第一次抓到資料的隔天才會出現。
- ETF 有人申購或買回時，所有持股股數會等比例增減，那不是經理人的決定；比對時改看「每單位持有幾股」，變化 2% 以上才算加碼或減碼。
- 持股裡不在熱力圖股票池的股票只顯示權重，沒有即時漲跌。
- 每次推送到 `main` 部署時也會順便更新；想立刻更新可以到 GitHub 的 Actions →「Deploy to GitHub Pages」→ Run workflow。
- 抓取程式在 `scripts/active-etf.ts`，比對邏輯在 `src/data/activeEtfDiff.ts`。

其餘 ETF 的股價、淨值、規模、配息、費用率、成分股權重與異動仍是模擬資料（`src/data/mockEtfs.ts`）。

## 五大核心選股

| 策略 | 條件（全部成立才算符合，特殊事件為任一成立） |
|---|---|
| 低基期低本益比（Value） | 股價位於自身近 3 年區間的低檔 30% 內；本益比位於自身近 5 年分布的 30% 分位以下（沒有歷史時改為低於產業中位數的 8 折）；連續配息 5 年以上且自由現金流為正 |
| 動能與成長（Growth） | 近四季 EPS 年增 > 20%；毛利率與營益率皆提升；股價距一年高點 5% 內 |
| 高股息存股（Income） | 殖利率 > 5%；股利發放率 50%–80%；連續配息 10 年以上 |
| 特殊事件（Event-Driven） | 法說會展望調升；企業併購 / 資產活化；政策補貼 |
| 籌碼與技術（Technical） | 法人連買 3 天以上；千張大戶持股比率 4 週內上升；均線多頭排列、成交量 ≥ 常態 1.2 倍且突破 20 日高點 |

只差一個條件的股票標為「接近」。本益比、殖利率、股價位階、一年高點距離與量價突破都用即時股價計算。

「便不便宜」不用統一標準：金融股 10 倍、半導體 20 倍以上都很常見，所以本益比和股價位階都和**這檔股票自己的歷史**比。
個股分析頁的「評價位置」會畫出目前本益比在近 5 年區間的位置（灰線是產業中位數），以及股價在近 3 年區間的位置。
目前 5 年本益比分布是模擬資料；之後由證交所每日本益比資料計算。
模擬模式的基本面、籌碼與事件都是**模擬資料**（`StockMeta.fundamentals`）；真實行情模式會換上官方的本益比、殖利率、
法人、千張大戶、財報、配息與重大訊息（見下方「換成官方資料的部分」）。

熱力圖只放約 120 檔代表性股票；不在裡面的股票改用「全市場股票目錄」：

- GitHub Actions 每次部署（含每天的排程）從證交所、櫃買中心開放資料整理出所有股票的名稱、產業、最近收盤、成交量值，
  以及官方公布的本益比、殖利率、股價淨值比，存成 `data/stocks.json`（程式在 `scripts/stock-list.ts`）。
- 這些股票的價格：模擬模式顯示最近收盤；真實行情模式每 30 秒查一次即時報價（富果或證交所轉接）。
- 本益比、殖利率是官方資料（標示資料日期），其餘基本面與籌碼仍是模擬；不在熱力圖裡，所以沒有資金流。

日 K 只用真實資料，來源依序是：

1. 富果（有填金鑰時）：一次抓近一年日 K。抓失敗時圖上會顯示富果回傳的錯誤原因。
2. 證交所／櫃買每日收盤行情：GitHub Actions 每天收盤後抓全市場一次（上市、上櫃各一次請求），
   累積成 `data/candles/<代號>.json`；第一次會分幾次部署回補近一年。
3. 都沒有時不畫圖（不再用亂數走勢代替），只有「模擬行情」模式的熱力圖股票會用示意日 K。
摘要是依指標規則自動整理的文字，不構成投資建議。


有兩種真實資料來源，在右上角 **☰ 選單 → 資料來源** 切換：

| | 富果 | 證交所 |
|---|---|---|
| 需要 | 富果 API 金鑰 | 自己部署一個免費的 Cloudflare Worker 轉接服務 |
| 熱力圖更新 | 約 2～3 分鐘一輪（5 檔逐筆） | 約 10 秒一輪 |
| 成交額 | 實際成交金額 | 成交量 × 均價的估計值 |
| 穩定度 | 正式 API | 非正式公開介面，查太頻繁會被暫時封鎖，格式可能變動 |

兩種都只適合自己使用；即時行情不能公開轉載。

## 拉普拉斯模擬盤

按左上角的「拉普拉斯之眼」圖示，播放一段全畫面動畫後進入模擬盤（網址 `#sim`）。這個圖示也是網頁分頁與手機加到主畫面的圖示。

模擬盤裡只顯示模擬相關的畫面（頂端列只剩圖示與「離開」）。

### 開通碼

- 進入模擬盤要先輸入開通碼。每個開通碼有自己的存檔；登入後可以選「接續上次的模擬」或「開新的模擬」（舊的一局會存進歷史紀錄）。
- 產生開通碼：`node scripts/sim-code.mjs "朋友名稱" [個數]`（40 碼；加 `--reset` 會作廢全部舊碼並重新產生），開通碼只會印出這一次；`web/public/sim-codes.json` 只存雜湊與名稱（名稱登入後會顯示，會公開在網站上）。commit 後部署就生效。
- 停用開通碼：從 `sim-codes.json` 刪掉那一筆。
- 在模擬盤再按一次左上角圖示（或「離開」），播放「闔眼」動畫後回到進來之前的頁面。
- 開通碼只是入口，不是嚴格的權限控管（網站本身是公開的靜態網頁）。

### 跨裝置同步（Firebase 免費方案）

存檔會先存在瀏覽器，再同步到 Firestore；換裝置用同一個開通碼登入就能接續。沒有設定時只存在本機。

1. 到 [Firebase 主控台](https://console.firebase.google.com/) 建立專案（不用開 Google Analytics），方案維持免費的 Spark。
2. 「建構 → Firestore Database → 建立資料庫」，選正式版模式（production mode），位置選 `asia-east1`（台灣）。
3. 「規則」分頁貼上 repo 根目錄 `firestore.rules` 的內容並發布。
4. 「專案設定 → 一般 → 你的應用程式」新增網頁應用程式，複製 `projectId` 與 `apiKey`，寫進 `web/public/sync-config.json`：
   `{ "projectId": "你的專案ID", "apiKey": "你的 apiKey" }`（這兩個值本來就是公開的，安全性靠規則與開通碼）。

目前使用的專案是 `lpsdsystem`。

**自動更新安全規則**：修改 `firestore.rules` 並合併到 main 後，`.github/workflows/deploy-firestore-rules.yml` 會自動部署到 Firebase。
需要先在 GitHub repo 的 Settings → Secrets and variables → Actions 新增 `FIREBASE_SERVICE_ACCOUNT`，
內容是 Firebase 主控台「專案設定 → 服務帳戶 → 產生新的私密金鑰」下載的整個 JSON（這把金鑰權限很大，只放在 GitHub Secrets，不要 commit）。
並在 [Google Cloud IAM](https://console.cloud.google.com/iam-admin/iam?project=lpsdsystem) 幫這個服務帳戶（`firebase-adminsdk-…`）加上「Firebase Rules Admin」角色。

每個開通碼一份文件 `sims/<同步 ID>`，同步 ID 由開通碼算出，和 `sim-codes.json` 裡的雜湊不同，沒有開通碼就讀寫不到。
兩台裝置同時玩時，以雲端上較新的進度為準。

- 選一個過去的日期（或按「隨機日期」）與本金，用模擬帳戶一天一天往前回放。K 線只畫到目前這一天，看不到未來。
- 收盤後下單、下一個交易日成交：市價單用開盤價；限價單當天碰到限價才成交，否則取消。
- 手續費 0.1425% × 折扣（整股最低 20 元、零股 1 元），賣出證交稅 0.3%（ETF 0.1%）。
- 一價漲停買不到、一價跌停賣不掉；當天沒有成交就取消。除息現金在除息日入帳，除權依參考價換算配股（近似）。
- 會顯示總資產、報酬率、同期加權指數、最大回檔、勝敗次數與交易紀錄；可以開關「型態提示」（只用到目前日期的資料判斷）。
- 帳戶存在這台裝置的瀏覽器（localStorage `lplc.sim.v1`），按 → 鍵前進一天、Shift + → 前進五天。

## 使用證交所即時行情

證交所的即時報價不允許網頁直接查詢，所以要先架一個「轉接服務」：它代替網頁去問證交所，
再把結果交回網頁。用 Cloudflare Workers 免費方案即可（每天 10 萬次請求，這個網站一天約用 5 千次）。

### 1. 部署轉接服務（只要做一次）

1. 到 [dash.cloudflare.com](https://dash.cloudflare.com) 註冊或登入 Cloudflare（免費）。
2. 左側選單進入 **Workers & Pages**（新版介面在 **Compute (Workers)** 底下），按 **Create** → **Start with Hello World!**。
3. 名稱填 `lplc-twse`（可自訂），按 **Deploy**。
4. 部署完按 **Edit code**，把左邊編輯器的內容全部刪掉，貼上 repo 裡 [`worker/twse-proxy.js`](../worker/twse-proxy.js) 的全部內容，按右上角 **Deploy**。
5. 複製這個 Worker 的網址，長得像 `https://lplc-twse.你的帳號.workers.dev`。
6. 想確認有沒有成功：在瀏覽器直接打開這個網址，看到「這個網站沒有被允許使用轉接服務」就代表 Worker 有在運作（直接打開沒有帶網站來源，所以被擋是正常的）。

`twse-proxy.js` 最上面的 `ALLOWED_ORIGINS` 列出可以使用這個轉接服務的網站，預設是
`https://znxuyz.github.io` 和本機開發網址。repo 改名不影響（網域不變），但如果改用自己的網域，要把新網域加進去再 Deploy。

### 2. 在網站上設定

1. 打開網站，點右上角 **☰ 選單**，在「資料來源」按 **證交所**。
2. 「證交所轉接網址」貼上剛剛的 Worker 網址。
3. 「富果 API 金鑰」是選填：填了會用富果日 K 算真實的 20 日常態成交額（資金流比較準）；不填就用內建估計值。
4. 按 **儲存並連線**，Logo 旁的標籤會顯示 `證交所載入` → `證交所即時`（盤中）或 `證交所・休市`。
5. 出現 `無法連線轉接服務`：檢查網址有沒有貼錯、Worker 有沒有 Deploy、`ALLOWED_ORIGINS` 有沒有包含目前網站。

## 使用富果即時行情

### 1. 取得富果 API 金鑰

1. 到 [富果開發者平台](https://developer.fugle.tw) 用富果帳號登入（只需要富果會員，不需要證券戶）。
2. 進入「API 金鑰」頁面，建立一把金鑰，複製起來。
3. 方案用免費的基本用戶即可。

### 2. 在網站上設定

1. 打開網站，點右上角的 **☰ 選單**（或點 Logo 旁的「模擬行情」小標籤），在「資料來源」按 **富果**。
2. 在「富果 API 金鑰」欄位貼上金鑰，按 **儲存並連線**。頁面會重新載入。
3. Logo 旁的小標籤會變成：
   - `富果載入 xx%`（藍色）：第一次使用時正在抓報價與 20 日常態成交額，約 2～3 分鐘。
   - `富果即時`（綠色）：盤中，報價持續更新。
   - `富果・休市`（灰色）：盤後、假日，顯示最後一個交易日的資料。
   - `API 金鑰無效` / `無法連線富果`（紅色）：見下方〈疑難排解〉。
4. 想回到模擬行情：選單裡按 **模擬**；按 **清除** 會刪掉金鑰、轉接網址並回到模擬行情。

金鑰只存在這台裝置的瀏覽器（localStorage），不會寫進程式碼，也不會上傳到 GitHub。
換一台電腦或手機要重新貼一次。不要在公用電腦上使用，或用完按「清除」。

### 3. 更新頻率（免費方案的限制）

| 資料 | 來源 | 更新 |
|---|---|---|
| 熱力圖所有股票、ETF 的價格與成交額 | Intraday API，每分鐘 55 次輪流查詢 | 約 2～3 分鐘一輪 |
| 市值最大的 4 檔＋目前點選的股票 | WebSocket（5 檔上限） | 逐筆即時 |

當天的報價與每分鐘紀錄也會存在瀏覽器，重新整理不會從零開始。

### 4. 疑難排解

| 狀況 | 原因與處理 |
|---|---|
| `API 金鑰無效` | 金鑰貼錯、多了空白或已失效。到富果開發者平台確認後重新貼上。 |
| `無法連線富果` | 網路問題，或富果不允許從網頁直接呼叫（CORS）。先重新整理再試；仍然失敗就需要加一個轉接服務（例如免費的 Cloudflare Worker）。 |
| 標籤一直停在 `富果載入` | 第一次載入要 2～3 分鐘；若超過 5 分鐘，打開選單看哪一項沒有前進。 |
| 部分股票一直是灰色 0% | 富果查無該代號，選單的詳細狀態會列出「富果查無」。 |
| WebSocket 未連線 | 不影響使用，只是那 5 檔會改成跟其他股票一樣 2～3 分鐘更新。 |

## 定義

| 項目 | 定義 |
|---|---|
| 成交佔比 | 個股今日成交額 ÷ 今日總成交額 |
| 常態 | 近 20 日平均成交額的佔比 |
| 資金流 | （成交佔比 − 常態）× 今日總成交額；所有個股加總為 0 |

## 結構

```
src/
  data/       資料層：型別、MarketDataProvider 介面、mock 股票池與模擬行情、真實行情（fugle.ts 富果、twseMis.ts 證交所、liveProvider.ts）
  domain/     資金流（metrics.ts）、資金輪動（rotation.ts）、事件偵測（events.ts）、五大選股（screens.ts）、ETF（etf.ts）、
              技術指標（technicals.ts）、個股分析（analysis.ts）、新聞（news.ts）
  ui/         玻璃熱力圖、事件通知、輪動條碼、選股頁、ETF 頁與各資訊面板
  main.ts     組裝：provider → metrics → views / panels
../worker/    證交所即時行情的 Cloudflare Worker 轉接服務
```

接真實資料時，實作 `src/data/provider.ts` 的 `MarketDataProvider`，
把行情轉成 `src/data/types.ts` 的格式即可，UI 與領域邏輯不需要修改。
