# L.P.L.C. 資金指揮台（原型）

L.P.L.C.-System 的第一個視覺化模組，用來看「錢今天流到哪裡」。介面採科幻戰術指揮台風格：
斜切角面板、霓虹青介面色、掃描線與雷達；紅綠只用於漲跌，琥珀色用於警示。目前使用 **mock 行情**，
資料層已抽象化，之後可以直接換成富果或證交所資料。

## 視圖

| 視圖 | 讀法 |
|---|---|
| **資金領地**（主畫面） | 地圖依面積切成 500–1800 個六角格（格子大小固定，地圖越大格數越多），每格代表相同的成交額，成交越大的股票佔越多格，同產業連成一片領地，產業邊界是霓虹線。顏色 = 漲跌；全亮 = 成交高於常態（吸金），變暗 = 低於常態（失血）；吸金最強的 6 檔脈衝發光；盤中被別的股票奪下的格子會閃光。版面用 resquarify 排列，只有邊界的格子會易主。 |
| **資金雷達**（第二分頁） | 光點面積 = 今日成交額，同產業聚在同一個方位；資金流入越多越靠近中央，流出越多越靠外圈。 |
| **作戰日誌**（右側） | 自動偵測盤中事件：產業資金轉向、資金龍頭易主、資金流每突破 50 億、個股漲跌超過 5% 或觸及漲跌停、大盤漲跌突破整數百分比。 |
| **資金輪動條碼**（底部） | 每列一個產業、每格 5 分鐘，顏色 = 該時段成交佔比偏離常態的百分點，看得出盤中輪動。 |

點產業或股票會在所有視圖與右側面板同步標示，Esc 取消選取。按「放大地圖」或 F 鍵讓地圖佔滿畫面（左右欄與底部收起，最新作戰日誌浮在地圖角落），Esc 還原。

## 定義

| 項目 | 定義 |
|---|---|
| 成交佔比 | 個股今日成交額 ÷ 今日總成交額 |
| 常態 | 近 20 日平均成交額的佔比 |
| 資金流 | （成交佔比 − 常態）× 今日總成交額；所有個股加總為 0 |
| 領地格數 | 成交佔比 × 總格數（每格 = 今日總成交額 ÷ 總格數） |

## 開發

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # 資金流、六角格領地、輪動、作戰日誌、模擬行情測試
npm run build      # 型別檢查 + 打包到 dist/
```

## 結構

```
src/
  data/       資料層：型別、MarketDataProvider 介面、mock 股票池與模擬行情
  domain/     資金流（metrics.ts）、資金輪動（rotation.ts）、作戰日誌（events.ts）
  layout/     六角格網與領地分配（hexgrid.ts）
  ui/         資金領地、資金雷達、輪動條碼與各資訊面板
  main.ts     組裝：provider → metrics → views / panels
```

接真實資料時，實作 `src/data/provider.ts` 的 `MarketDataProvider`，
把行情轉成 `src/data/types.ts` 的格式即可，UI 與領域邏輯不需要修改。
