# L.P.L.C. System

**Laplace Predictive Leading Core**（拉普拉斯預測型領先核心系統）—— 台股資金流向、選股、個股分析與歷史回放模擬交易的網站。

🔗 **網站**：<https://znxuyz.github.io/L.P.S.D-System/>（可以「加到主畫面」當成 App 使用，離線也打得開）

## 功能總覽

網站分成八個頁面，網址的 `#` 後面可以直接指定（例如 `#stock/2330`）：

| 頁面 | 網址 | 做什麼 |
|---|---|---|
| 熱力圖 | `#map` | 方塊面積＝今日成交額、顏色＝漲跌幅，依產業分組；看「錢今天流到哪裡」。盤中事件從左下角跳出通知。 |
| 市場情報 | `#intel` | 產業資金流排行、加權指數與台指期、資金輪動（每 5 分鐘各產業的成交佔比變化）、盤中事件紀錄；今日排行（熱力圖股票池即時，或全市場最近一個交易日收盤）與新聞（國內外大事件與重大訊息）；大盤風險：上市融資維持率（低於約 140% 常出現斷頭賣壓）、融資餘額、券資比、外資台指期淨未平倉。 |
| 五大選股 | `#screen` | 低基期低本益比、動能成長、高股息、特殊事件、籌碼技術五種策略的條件與篩選結果，可以一鍵在熱力圖上亮出來。 |
| ETF | `#etf` | 殖利率、配息、折溢價、規模、受益人數、填息率、成分股與成分股變化。淨值、規模、受益人數、配息、填息每天抓官方資料；主動式 ETF 每天抓投信公告的真實持股，比對加碼／減碼。內扣費用率與被動式 ETF 的成分股沒有公開資料，仍是模擬值（畫面上標「模擬」）。 |
| 個股分析 | `#stock/<代號>` | 全部上市櫃股票與 ETF：日 K、20 多種型態自動辨識（附歷史勝率，分多頭／空頭行情）、技術指標、籌碼、基本面、綜合評分。；可以按「☆ 加入自選」，熱力圖的「★ 自選」亮出自選股。 |
| 股市入門 | `#learn` | 分成基本、K 棒、K 線圖、型態指標、基本面籌碼、ETF 六類，上方分頁直接切換（手機上分頁列會黏在畫面上方）。內容有 K 棒、K 線圖（日K／週K）、均線、成交量、趨勢與型態、技術指標、基本面、籌碼、下單與費用、ETF 的白話說明與示意圖；「K 棒實驗室」可以拉動開高低收，看 K 棒怎麼變、代表什麼。 |
| 預測 | `#predict` | L.P.L.C. 的預測模型（見下方「預測」）：個股未來 20 日的強弱排名（最看好／最該避開）、大盤 20 日上漲機率、00631L 當沖訊號（輸入開盤價就算出做多／做空／觀望）。每個模型都附樣本外回測，沒有預測能力的直接標出來。 |
| 拉普拉斯模擬盤 | `#sim` | 按左上角的「拉普拉斯之眼」進入。回到過去某一天，用模擬帳戶在盤中行情裡交易（見下方）。需要開通碼。 |

行情有四種模式，在右上角 ☰ 選單切換：
- **收盤**（預設，不需要金鑰）：最近一個交易日的真實收盤資料（開高低收、成交量、成交額）。按「重新開盤」可以回放那一天，回放時每分鐘的跳動是依開高低收推算的模擬走勢，收盤數字一定是真的。
- **模擬**：示意行情，數字不代表實際市場。
- **富果**：盤中即時行情，需要自己的 API 金鑰。盤中才打開網頁也會用當日 1 分 K 補上 09:00 開盤以來的走勢與資金流。
- **證交所**：盤中即時行情，需要自己部署轉接服務。

金鑰只存在自己的瀏覽器，不會上傳。設定方式見 [`web/README.md`](web/README.md#使用富果即時行情)。

## 預測

`scripts/predict.ts` 在每次部署時用 data 分支的資料重新計算，輸出 `predict.json`。三個模型都是**逐段往前滾**（walk-forward）：每個時間點只用當時已經揭曉的資料訓練、再預測之後，所以頁面上的回測成績都是樣本外的。

| 模型 | 預測什麼 | 用到的資料 | 方法 |
|---|---|---|---|
| 個股排名 | 未來 20 個交易日相對其他股票的強弱（近 20 日平均成交額 0.3 億以上的個股） | 近 5／20 日與 12－1 個月動能、離一年高點、季線、波動度、量能、成交規模、法人 5／20 日買賣超、融資增減、本益比、殖利率、淨值比、EPS 與營收年增（16 個因子，每天在全市場排名） | 嶺迴歸（因子排名＋排名平方），每 20 個交易日重新訓練。進出場：等拉回再買、停利、停損（依 ATR，64 種）每期只用已結束的期間挑；目前回測單純「隔天開盤買、20 天後賣」最好，另附參考停損（收盤 − 2.5×ATR）與它的報酬／風險取捨 |
| 大盤展望 | 加權指數未來 20 個交易日上漲機率與預期報酬 | 指數動能與波動、站上季線的股票比例、融資維持率與餘額、券資比、外資台指期淨未平倉、法人買賣超 | 邏輯迴歸／嶺迴歸（較強的 L2，樣本少） |
| 00631L 當沖 | 當天開盤到收盤的報酬；超過交易成本（手續費不打折來回（保守）＋證交稅 0.1%）才做多／做空 | 開盤跳空、前一天的漲跌與振幅、近 5／20 日漲跌、波動度、全市場法人買賣超、外資期貨與融資維持率變化 | 嶺迴歸；開盤前除了跳空都已知，所以頁面直接換算成「開盤價多少以上做多／以下做空」 |
| 00631L 整天 5 分 K | 以 5 分鐘為單位畫整天的預測線：綜合預測（主要預測線，模型主線與相似日平均依過去誤差自動混合）、模型主線、相似日走勢線（歷史上到目前為止最像的 3 天，接下來的真實走勢依波動縮放）與相似日平均；也可以畫預測 K 棒、80% 區間與預估今日最高／最低。開盤前先預測跳空，盤中每走完一根就重新預測。相似日平均取幾天、綜合預測的混合比例，每個預測時間點都用「到前一天為止」的實際誤差自動挑。當天進出場點：09:30／10:00 依預估上下幅度同時掛買進與放空單、停利停損、收盤出場（144 組設定逐段往前滾挑，過去獲利要統計顯著才出手，否則建議不交易；不交易時畫參考價位）。每條線都附樣本外的準確度（每根誤差、收盤方向命中、最接近實際的比例）與最近 20 天的預測紀錄。有即時行情時預測今天，否則回放最近 10 天（可疊上實際走勢比對誤差） | 加權指數 5 分 K（證交所每 5 秒指數統計，`scripts/intraday.ts` 從 2020 年回補）、日 K、外資期貨 | 四組嶺迴歸（`scripts/predict-intraday.ts`，特徵與預測在 `web/src/domain/intradayModel.ts`，網頁共用）：收盤走勢（1～12 根與到收盤）、每根振幅（時段平均 × 今天／昨天的波動）、剩下時間的最高最低、開盤跳空；每次訓練用最後 20% 的資料挑誤差最小的正則化強度；區間依時段與當天波動放大縮小。00631L 用「β × 加權指數報酬」換算 |

**前一晚美股**：台股開盤前美股已經收盤，所以 00631L 當沖、5 分 K（跳空、走勢、相似日）都加上「上一個台股交易日到今天開盤前」收盤的費城半導體、台積電 ADR、S&P 500 漲跌（`scripts/lib/usMove.ts`）。

**臺指期夜盤**：期交所把 D 日前一晚的夜盤（15:00～05:00）標成 D 日；D 開盤前用「夜盤收盤 ÷ 上一個交易日一般時段收盤」（`scripts/taifex-daily.ts`、`scripts/lib/txNight.ts`）。**模型自己決定要不要用**美股與夜盤：每次訓練用最後 20% 的資料比較四種組合，挑誤差最小的（不用的那組係數為 0）。

**事前存檔**分兩次：每天收盤後（還不知道當晚美股）與隔天早上 05:47（07:13 備援；加上前一晚美股與臺指期夜盤，`.github/workflows/morning-forecast.yml`，只能在 05:00～08:45 存成 `*-pre`），都在開盤前；實盤成績優先用早上那份。存檔只新增、不覆蓋，git 的提交時間證明是事前做的。

**營收選股**（`scripts/lib/revSignals.ts`，研究用 `scripts/factor-lab.ts`）：從根本原因選股——股價長期跟著公司賺多少錢走，每月營收（`scripts/revenue.ts`，公開資訊觀測站，2019 年起）是台股最早公布的獲利資料。綜合分數＝營收成長加速、營收創新高程度、毛利率改善、法人買超在全部股票裡的排名平均；每月 12 日後第一個交易日換成最高的 20 檔，「營收是一次性的」（近 3 個月單月佔 60% 以上）不買。加權指數在 200 日均線之下就持有現金。逐段往前滾回測 2021-01～2026-11：+452% vs 加權指數 +184%（2024 年輸大盤）。每天收盤後把前 30 名「買／觀察／不買」與原因存進事前存檔，之後自動追蹤每個決定的實際報酬；內部人申報轉讓（`scripts/insider.ts`，開放資料只有當天，從 2026-11 起累積）與外資、投信分開的買賣超（`inst2/`）先收集，驗證有用才放進模型。

**個股預測**（預測頁）：搜尋任一檔股票，日 K 未來一個月的中線（同分數組的歷史平均）、80% 區間（回測各年約 80% 落在區間內）與相似走勢預測線（附這檔自己的回測準確度；17 檔常見股票平均方向只有約 51%，頁面誠實標示）。個股的盤中 K 線沒有公開歷史，改用富果歷史 1 分 K（金鑰在 GitHub Secret，資料只存在私人儲存庫，不放公開的 data 分支）。

**00631L 盤中預測**可以切換 5 分、3 分、1 分 K（加權指數每 5 秒資料切成 54／90／270 根，`setTimeframe()`；預測長度與特徵以分鐘定義）。

**模型模擬帳戶**（`scripts/paper-trade.ts`，預測頁最上面）：本金 100 萬，完全照事前存檔的預測自動交易（紙上交易），用之後實際的開盤價、收盤價成交、扣手續費（不打折、每筆最低 20 元）與證交稅；每檔不足一張的部分當作買零股，成交價比開盤價差 0.5%（保守）：趨勢 50%（加權指數前一天收在 200 日均線之上持有 00631L，持有比例依波動調整＝長期一般波動 ÷ 近 20 日波動、最多 100%；跌破就換現金）、營收選股 50%；現金以年息 1.5% 計。2022 年起的歷史回測（2026-11-20 為止，含零股成本）+166% vs 加權指數 +98%、最大回落 −35%（不依波動調整的版本頁面並列）。營收選股「分兩批輪流換」只當對照（`paper-backtest-2t.json`），保留期輸給每月全換所以沒採用。每次部署從第一份存檔重新計算。走向真錢的流程與停止條件事先寫死在頁面上：模擬實盤 60 個交易日 → 小錢 10% 實戰 60 個交易日 → 每 60 個交易日最多加 20%；落後加權指數超過 15 個百分點或回落超過 35% 就停。每小時記錄每家公司月營收「第一次看到」的時間（`scripts/revenue-dates.ts` → `revdates/`），累積幾個月後驗證「一公布就買」。每天晚上與每週六有自動檢查（排程），只修程式與資料問題，模型要用足夠的資料逐段往前滾驗證才改。

**有沒有預測能力**由程式自動判斷（資料變多後會重新判斷）：個股排名看排名相關係數（IC）的 t 值是否大於 2；大盤看方向準確率是否高於「一直猜漲」、機率誤差是否低於基本上漲率；當沖看扣成本後是否累計賺錢。
目前（2026-11）的結果：營收選股與「趨勢＋波動調整」回測贏大盤（但都是看過歷史後決定的配置，公正的成績要看之後的實盤）；舊的逆勢個股排名、大盤方向、00631L 當沖與盤中 K 線的漲跌方向**沒有**勝過簡單基準（頁面上標示觀察用）；盤中的振幅、今日高低點與開盤前的跳空預測有用。

## 拉普拉斯模擬盤

用真實的歷史行情練習交易，但**看不到日期**，不能靠記憶作弊。

### 時間與畫面
- 每個交易日先停在 08:30 盤前，按「開盤」後 09:00 開盤、13:30 收盤，**現實 1 秒＝盤中 1 分鐘**，可選 1×／3×／5×。可以暫停（暫停時不能交易）或直接跳到隔天，不能倒帶。收盤後自動進入下一個交易日。
- 畫面上只看得到「第幾天、星期幾、幾點」；年月日顯示成不停跳動的亂碼，新聞也只有亂碼日期。可以選「隨機日期開始」：多半從值得練習的行情裡抽（疫情 V 轉、航運狂潮、2022 升息空頭、AI 狂潮、2024 年 8/5 大跌、2025 關稅風暴等，起點在事件前幾週），其他時候抽一個任意日期；起點一定離最新資料至少一年，才玩得夠久。抽到哪個行情結束報告才揭曉。
- 盤中每分鐘的價格是**模擬**的：每天的開、高、低、收是真實資料，中間的跳動依這四個價格推算（同一檔同一天每次都一樣）。
- 今日排行（漲幅、跌幅、成交量、高價、低價，約 2,000 檔）、新聞欄（國內外大事件改寫的標題、公司重大訊息、盤勢）、型態提示（只用到昨天收盤為止的資料）。

### 畫面分頁
- **手機**：分成「📈 交易／🗺️ 熱力圖／💼 持股／💰 資金／🔍 分析／🎯 選股／🏆 排行／📰 新聞」，分頁列捲動時黏在畫面上方，一次只顯示一類。
- **電腦**：K 線圖與下單一直顯示，K 線下面的分頁切換熱力圖、持股、資金、分析、選股、排行、新聞；「📘 股市入門」整個主畫面換成入門內容。

### 熱力圖
模擬當天全市場的熱力圖（股票池與首頁相同），跟著模擬時鐘每分鐘更新，列出資金最集中與撤出最多的產業；成交額依張數與均價估算。
下方可以展開「大盤風險」：前一個交易日的上市融資維持率、融資餘額、券資比與外資台指期淨未平倉（不顯示日期）。

### 五大選股
首頁五大選股的同一套條件，每個交易日收盤後用**當時看得到的資料**對全市場篩選一次（`scripts/sim-screen.ts`，部署時產生），模擬時看前一個交易日的結果。
配息資料從 2016 年起、千張大戶只有最近一年：資料不夠時「連續 10 年配息」改成資料起點以來每年都配息（至少 5 年），千張大戶的條件略過；季報不到 8 季時 EPS 年增改用每日本益比反推的近四季 EPS 跟一年前比。

### 分析（基本面與技術分析）
- **基本面**：只看得到模擬當天**已經公布**的財報（季報過了申報期限才出現：Q1 5/31、Q2 8/31、Q3 11/30、Q4 隔年 3/31）。本益比、殖利率、股價淨值比用昨天收盤價計算；最近 8 季的營收、毛利率、營益率、EPS 與年增率。季別只寫「最新一季、前 1 季…」，不顯示年份。
- **技術分析**：EMA 均線排列、RSI、MACD、KD、布林通道、量能（盤中換算成全天預估量）、支撐壓力，各標偏多／偏空；外資＋投信近 5／20 日買賣超（到昨天為止）與千張大戶。

### 股市入門
右上角的「📘 股市入門」可以直接在模擬盤裡看 K 棒、K 線、均線等說明，打開時自動暫停，回到看盤再繼續。
K 線圖的三條線是 **EMA20／EMA60／EMA120**（指數移動平均，約一個月、一季、半年）。

### 新手指引
第一次進到遊戲畫面會問要不要看新手指引；之後隨時按右上角的「❓ 新手指引」。指引會一步一步框出每個區塊（其他地方變暗），
「功能說明」介紹這是什麼，「操作 ①～⑥」照實際下單順序帶一次：找股票 → 選類別 → 買或賣 → 數量 → 市價或限價 → 送出。

### 交易規則
| 項目 | 規則 |
|---|---|
| 盤前 | 每天先停在 08:30 盤前（看不到今天的價格），可以先下市價或限價單；按「🔔 開盤」以開盤集合競價撮合：市價單、買進限價 ≥ 開盤價、賣出限價 ≤ 開盤價都以開盤價成交，其他限價單留到盤中。不想每天停下來可以把「盤前停留」關掉。 |
| 委託 | 盤中市價單立刻以當下價格成交；限價單碰到價格才成交，收盤沒成交就取消。 |
| 停損／停利 | 針對部位設定，長效有效；盤中碰到就以市價了結整個部位。開盤跳空時視同參加開盤集合競價，以開盤價成交（一價鎖跌停時賣不掉）。 |
| 自選股 | 圖表上方按「☆ 自選」加入，今日排行的「自選」分頁看即時價格。 |
| 交易類別 | 現股；現股當沖（證交稅減半，收盤未沖銷自動沖銷）；融資（自備 40%、年息 6.5%）；融券（保證金 90%、借券費 0.08%）。整戶維持率低於 130% 提醒、低於 120% 收盤強制了結。 |
| 費用 | 手續費 0.1425% × 折扣（整股最低 20 元、零股 1 元）；賣出證交稅 0.3%（ETF 0.1%）。 |
| 其他 | 一價鎖漲停買不到、鎖跌停賣不掉；除權息自動處理。股票分割、面額變更、減資（例如 0050 一拆四）自動換算持股股數，總成本不變，停損停利價跟著換算，K 線圖把之前的價格還原成新基準（只還原已經發生的）。 |
| 破產 | 開新局時選擇破產條件：總資產（扣掉融資、貸款、質押借款）跌到 0、或虧掉累計投入的 80%／50% 時，當天收盤強制了結全部部位並結束這一局；也可以選「不會破產」。 |

### 資金
| 項目 | 規則 |
|---|---|
| 每月薪資投入 | 每個月第一個交易日開盤前入帳（預設 20,000，開新局時可改，0 = 不投入）。 |
| 定期定額 | 每個月第一個交易日薪資入帳後，以開盤價買進設定的金額（可以買零股），可以同時設定好幾檔。 |
| 信用貸款 | 額度 100 萬、年利率 3.5%、12～84 期本息平均攤還，每月第一個交易日自動扣款；可以隨時提前還款（之後月付金重算）。現金不夠扣款時，沒繳到的部分加 1% 違約金滾入本金。 |
| 股票質押 | 現股最多借市值的 60%、年利率 2.5%（每月扣息）；質押中的股票不能賣。維持率（市值 ÷ 借款）低於 130% 提醒、低於 120% 收盤強制賣出還款。 |

**報酬率＝總資產 ÷ 累計投入（本金＋薪資）－ 1**；貸款算負債，不算報酬。
「同額買大盤」是對照組：同樣的錢在同一天都拿去買加權指數，現在值多少。

### 結算、報告與排行
- **收盤結算**：每天收盤後列出當日損益（已實現／未實現）、持有部位的未實現損益、手續費與成交筆數。
- **結束報告**：一局結束時**揭曉真實日期**，並畫出報酬走勢（對照同額買大盤）、每日損益、回檔，列出賺最多與賠最多的股票。
- **歷史紀錄**：每局摘要都保留（最多 200 局），完整報告保留最近 10 局。
- **朋友排行榜**：大家玩的年代與速度不同，所以「日／週／月排行」是各自最近 1／5／20 個**模擬交易日**，依**超額報酬**（自己的報酬－同一段期間大盤的報酬）排名，另有「本局」排行。

### 帳號
- 每個開通碼一個帳號與存檔，會同步到雲端（換手機或電腦，用同一個開通碼登入就能接著玩）。
- 管理員（玩家 0）可以唯讀查看所有玩家的進行中模擬、持股、每一筆交易與每一局的報告（看得到真實日期）。
- 開通碼怎麼產生、怎麼停用，見 [維運手冊](docs/OPERATIONS.md#開通碼)。

## 技術架構

- **前端**：Vite＋TypeScript＋d3，純靜態網頁，部署在 GitHub Pages。Service Worker 讓網頁可以離線打開、從主畫面秒開。部署時產生 `version.json`，網頁打開、從背景叫回來、每 15 分鐘會比對一次，有新版就自動重新載入（加到主畫面的 App 也會更新；模擬盤播放中不打斷，暫停後才更新）。
- **資料管線**：`scripts/*.ts`（Node 直接執行 TypeScript）由 `.github/workflows/update-data.yml` 排程執行，結果推到 `data` 分支。
- **模擬盤雲端存檔**：Firebase Firestore 免費方案，用 REST API（不載入 Firebase SDK）。安全規則只接受白名單上的帳號，排行榜用雜湊鏈驗證只有本人寫得進去。
- **證交所轉接**：`worker/twse-proxy.js`（Cloudflare Workers 免費方案，自行部署，選用）。

```
.github/workflows/   update-data（資料更新）、deploy-pages（網站部署）、deploy-firestore-rules（安全規則部署）
scripts/             資料抓取與整理、預測模型（predict.ts、lib/ml.ts）、型態勝率回測、模擬盤每日行情與新聞、開通碼工具（sim-code.mjs）
web/                 網站原始碼（說明見 web/README.md）；web/public/media/ 放功能介紹影片與封面
  src/data/          資料載入、即時行情、帳號與雲端同步
  src/domain/        資金流、選股、技術指標、型態辨識
  src/domain/sim/    模擬盤引擎，依職責分檔：config（規則參數）、types、state（新局／舊存檔）、valuation（市值）、
                     orders（下單撮合）、bank（信貸質押定期定額）、session（開盤收盤、分割、破產）、market、summary
  src/ui/            各頁面；模擬盤畫面在 ui/sim/（dataStore 資料層、rank 排行、panels 面板、analysis 分析…）
  src/styles/        樣式，依頁面分檔，index.css 依序載入（順序就是層疊順序）
worker/              證交所即時行情轉接服務
firestore.rules      模擬盤雲端存檔的安全規則（合併到 main 後自動部署）
docs/OPERATIONS.md   維運手冊
```

## 開發

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm test         # 單元測試
npm run build    # 型別檢查＋打包
```

推到 `main` 後會自動部署網站；改了 `firestore.rules` 也會自動部署安全規則。日常維護（開通碼、Firebase、資料更新、疑難排解）見 [`docs/OPERATIONS.md`](docs/OPERATIONS.md)。

## 聲明

本網站的分析、評分、型態辨識與勝率都是依規則自動計算的結果，**不構成投資建議**。模擬盤的盤中走勢是依開高低收推算的模擬走勢，不是真實的盤中行情。
