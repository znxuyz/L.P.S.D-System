# L.P.L.C. System

**Laplace Predictive Leading Core**（拉普拉斯預測型領先核心系統）—— 台股資金流向、選股、個股分析與歷史回放模擬交易的網站。

🔗 **網站**：<https://znxuyz.github.io/L.P.S.D-System/>（可以「加到主畫面」當成 App 使用，離線也打得開）

> 名稱來自「拉普拉斯惡魔」思想實驗：如果知道現在的一切，就能推算未來。
> 這個系統把每天的行情、籌碼、財報與事件整理成看得懂的畫面；模擬盤則反過來，讓你回到過去、在看不到未來的情況下練習判斷。

## 功能總覽

網站分成七個頁面，網址的 `#` 後面可以直接指定（例如 `#stock/2330`）：

| 頁面 | 網址 | 做什麼 |
|---|---|---|
| 熱力圖 | `#map` | 方塊面積＝今日成交額、顏色＝漲跌幅，依產業分組；看「錢今天流到哪裡」。盤中事件從左下角跳出通知。 |
| 市場情報 | `#intel` | 產業資金流排行、加權指數與台指期、資金輪動（每 5 分鐘各產業的成交佔比變化）、盤中事件紀錄；今日排行（熱力圖股票池即時，或全市場最近一個交易日收盤）與新聞（國內外大事件與重大訊息）。 |
| 五大選股 | `#screen` | 低基期低本益比、動能成長、高股息、特殊事件、籌碼技術五種策略的條件與篩選結果，可以一鍵在熱力圖上亮出來。 |
| ETF | `#etf` | 殖利率、配息、折溢價、規模、受益人數、填息率、成分股與成分股變化。淨值、規模、受益人數、配息、填息每天抓官方資料；主動式 ETF 每天抓投信公告的真實持股，比對加碼／減碼。內扣費用率與被動式 ETF 的成分股沒有公開資料，仍是模擬值（畫面上標「模擬」）。 |
| 個股分析 | `#stock/<代號>` | 全部上市櫃股票與 ETF：日 K、20 多種型態自動辨識（附歷史勝率，分多頭／空頭行情）、技術指標、籌碼、基本面、綜合評分。；可以按「☆ 加入自選」，熱力圖的「★ 自選」亮出自選股。 |
| 股市入門 | `#learn` | 分成基本、K 棒、K 線圖、型態指標、基本面籌碼、ETF 六類，上方分頁直接切換（手機上分頁列會黏在畫面上方）。內容有 K 棒、K 線圖（日K／週K）、均線、成交量、趨勢與型態、技術指標、基本面、籌碼、下單與費用、ETF 的白話說明與示意圖；「K 棒實驗室」可以拉動開高低收，看 K 棒怎麼變、代表什麼。 |
| 拉普拉斯模擬盤 | `#sim` | 按左上角的「拉普拉斯之眼」進入。回到過去某一天，用模擬帳戶在盤中行情裡交易（見下方）。需要開通碼。 |

行情有四種模式，在右上角 ☰ 選單切換：
- **收盤**（預設，不需要金鑰）：最近一個交易日的真實收盤資料（開高低收、成交量、成交額）。按「重新開盤」可以回放那一天，回放時每分鐘的跳動是依開高低收推算的模擬走勢，收盤數字一定是真的。
- **模擬**：示意行情，數字不代表實際市場。
- **富果**：盤中即時行情，需要自己的 API 金鑰。
- **證交所**：盤中即時行情，需要自己部署轉接服務。

金鑰只存在自己的瀏覽器，不會上傳。設定方式見 [`web/README.md`](web/README.md#使用富果即時行情)。

## 拉普拉斯模擬盤

用真實的歷史行情練習交易，但**看不到日期**，不能靠記憶作弊。

### 時間與畫面
- 每個交易日先停在 08:30 盤前，按「開盤」後 09:00 開盤、13:30 收盤，**現實 1 秒＝盤中 1 分鐘**，可選 1×／3×／5×。可以暫停（暫停時不能交易）或直接跳到隔天，不能倒帶。收盤後自動進入下一個交易日。
- 畫面上只看得到「第幾天、星期幾、幾點」；年月日顯示成不停跳動的亂碼，新聞也只有亂碼日期。可以選「隨機日期開始」：多半從值得練習的行情裡抽（疫情 V 轉、航運狂潮、2022 升息空頭、AI 狂潮、2024 年 8/5 大跌、2025 關稅風暴等，起點在事件前幾週），其他時候抽一個任意日期；起點一定離最新資料至少一年，才玩得夠久。抽到哪個行情結束報告才揭曉。
- 盤中每分鐘的價格是**模擬**的：每天的開、高、低、收是真實資料，中間的跳動依這四個價格推算（同一檔同一天每次都一樣）。
- 今日排行（漲幅、跌幅、成交量、高價、低價，約 2,000 檔）、新聞欄（國內外大事件改寫的標題、公司重大訊息、盤勢）、型態提示（只用到昨天收盤為止的資料）。

### 畫面分頁
- **手機**：分成「📈 交易／🗺️ 熱力圖／💼 持股／💰 資金／🔍 分析／🏆 排行／📰 新聞／📘 入門」，分頁列捲動時黏在畫面上方，一次只顯示一類。
- **電腦**：K 線圖與下單一直顯示，K 線下面的分頁切換熱力圖、持股、資金、分析、排行、新聞；「📘 股市入門」整個主畫面換成入門內容。

### 熱力圖
模擬當天全市場的熱力圖（股票池與首頁相同），跟著模擬時鐘每分鐘更新，列出資金最集中與撤出最多的產業；成交額依張數與均價估算。

### 分析（基本面與技術分析）
- **基本面**：只看得到模擬當天**已經公布**的財報（季報過了申報期限才出現：Q1 5/31、Q2 8/31、Q3 11/30、Q4 隔年 3/31）。本益比、殖利率、股價淨值比用昨天收盤價計算；最近 8 季的營收、毛利率、營益率、EPS 與年增率。季別只寫「最新一季、前 1 季…」，不顯示年份。
- **技術分析**：EMA 均線排列、RSI、MACD、KD、布林通道、量能（盤中換算成全天預估量）、支撐壓力，各標偏多／偏空；外資＋投信近 5／20 日買賣超（到昨天為止）與千張大戶。

### 股市入門
遊戲畫面上方的「📘 股市入門」（手機是「入門」分頁）可以直接在模擬盤裡看 K 棒、K 線、均線等說明，打開時自動暫停，回到看盤再繼續。
K 線圖的三條線是 **EMA20／EMA60／EMA120**（指數移動平均，約一個月、一季、半年）。

### 新手指引
第一次進到遊戲畫面會問要不要看新手指引；之後隨時按上方的「❓ 新手指引」。指引會一步一步框出每個區塊（其他地方變暗），
「功能說明」介紹這是什麼，「操作 ①～⑥」照實際下單順序帶一次：找股票 → 選類別 → 買或賣 → 數量 → 市價或限價 → 送出。

### 交易規則
| 項目 | 規則 |
|---|---|
| 盤前 | 每天先停在 08:30 盤前（看不到今天的價格），可以先下市價或限價單；按「🔔 開盤」以開盤集合競價撮合：市價單、買進限價 ≥ 開盤價、賣出限價 ≤ 開盤價都以開盤價成交，其他限價單留到盤中。不想每天停下來可以把「盤前停留」關掉。 |
| 委託 | 盤中市價單立刻以當下價格成交；限價單碰到價格才成交，收盤沒成交就取消。 |
| 停損／停利 | 針對部位設定，長效有效；盤中碰到就以市價了結整個部位。開盤跳空時視同參加開盤集合競價，以開盤價成交（一價鎖跌停時賣不掉）。 |
| 自選股 | 圖表上方按「☆ 自選」加入，今日排行的「自選」分頁看即時價格。 |
| 交易類別 | 現股；現股當沖（證交稅減半，收盤未沖銷自動沖銷）；融資（自備 40%、年息 6.5%）；融券（保證金 90%、借券費 0.08%）。整戶維持率低於 130% 提醒、低於 120% 收盤強制了結。 |
| 費用 | 手續費 0.1425% × 折扣（整股最低 20 元、零股 1 元）；賣出證交稅 0.3%（ETF 0.1%）。 |
| 其他 | 一價鎖漲停買不到、鎖跌停賣不掉；除權息自動處理。股票分割、面額變更、減資（例如 0050 一拆四）自動換算持股股數，總成本不變，停損停利價跟著換算，K 線圖把之前的價格還原成新基準（只還原已經發生的）。 |
| 破產 | 開新局時選擇破產條件：總資產（扣掉融資、貸款、質押借款）跌到 0、或虧掉累計投入的 80%／50% 時，當天收盤強制了結全部部位並結束這一局；也可以選「不會破產」。 |

### 資金
| 項目 | 規則 |
|---|---|
| 每月薪資投入 | 每個月第一個交易日開盤前入帳（預設 20,000，開新局時可改，0 = 不投入）。 |
| 定期定額 | 每個月第一個交易日薪資入帳後，以開盤價買進設定的金額（可以買零股），可以同時設定好幾檔。 |
| 信用貸款 | 額度 100 萬、年利率 3.5%、12～84 期本息平均攤還，每月第一個交易日自動扣款；可以隨時提前還款（之後月付金重算）。現金不夠扣款時，沒繳到的部分加 1% 違約金滾入本金。 |
| 股票質押 | 現股最多借市值的 60%、年利率 2.5%（每月扣息）；質押中的股票不能賣。維持率（市值 ÷ 借款）低於 130% 提醒、低於 120% 收盤強制賣出還款。 |

**報酬率＝總資產 ÷ 累計投入（本金＋薪資）－ 1**；貸款算負債，不算報酬。
「同額買大盤」是對照組：同樣的錢在同一天都拿去買加權指數，現在值多少。

### 結算、報告與排行
- **收盤結算**：每天收盤後列出當日損益（已實現／未實現）、持有部位的未實現損益、手續費與成交筆數。
- **結束報告**：一局結束時**揭曉真實日期**，並畫出報酬走勢（對照同額買大盤）、每日損益、回檔，列出賺最多與賠最多的股票。
- **歷史紀錄**：每局摘要都保留（最多 200 局），完整報告保留最近 10 局。
- **朋友排行榜**：大家玩的年代與速度不同，所以「日／週／月排行」是各自最近 1／5／20 個**模擬交易日**，依**超額報酬**（自己的報酬－同一段期間大盤的報酬）排名，另有「本局」排行。

### 帳號
- 每個開通碼一個帳號與存檔，會同步到雲端（換手機或電腦，用同一個開通碼登入就能接著玩）。
- 管理員（玩家 0）可以唯讀查看所有玩家的進行中模擬、持股、每一筆交易與每一局的報告（看得到真實日期）。
- 開通碼怎麼產生、怎麼停用，見 [維運手冊](docs/OPERATIONS.md#開通碼)。

## 技術架構

- **前端**：Vite＋TypeScript＋d3，純靜態網頁，部署在 GitHub Pages。Service Worker 讓網頁可以離線打開、從主畫面秒開。部署時產生 `version.json`，網頁打開、從背景叫回來、每 15 分鐘會比對一次，有新版就自動重新載入（加到主畫面的 App 也會更新；模擬盤播放中不打斷，暫停後才更新）。
- **資料管線**：`scripts/*.ts`（Node 直接執行 TypeScript）由 `.github/workflows/update-data.yml` 排程執行，結果推到 `data` 分支。
- **模擬盤雲端存檔**：Firebase Firestore 免費方案，用 REST API（不載入 Firebase SDK）。安全規則只接受白名單上的帳號，排行榜用雜湊鏈驗證只有本人寫得進去。
- **證交所轉接**：`worker/twse-proxy.js`（Cloudflare Workers 免費方案，自行部署，選用）。

```
.github/workflows/   update-data（資料更新）、deploy-pages（網站部署）、deploy-firestore-rules（安全規則部署）
scripts/             資料抓取與整理、型態勝率回測、模擬盤每日行情與新聞、開通碼工具（sim-code.mjs）
web/                 網站原始碼（說明見 web/README.md）
  src/data/          資料載入、即時行情、帳號與雲端同步
  src/domain/        資金流、選股、技術指標、型態辨識
  src/domain/sim/    模擬盤引擎，依職責分檔：config（規則參數）、types、state（新局／舊存檔）、valuation（市值）、
                     orders（下單撮合）、bank（信貸質押定期定額）、session（開盤收盤、分割、破產）、market、summary
  src/ui/            各頁面；模擬盤畫面在 ui/sim/（dataStore 資料層、rank 排行、panels 面板、analysis 分析…）
  src/styles/        樣式，依頁面分檔，index.css 依序載入（順序就是層疊順序）
worker/              證交所即時行情轉接服務
firestore.rules      模擬盤雲端存檔的安全規則（合併到 main 後自動部署）
docs/OPERATIONS.md   維運手冊
```

## 開發

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm test         # 單元測試
npm run build    # 型別檢查＋打包
```

推到 `main` 後會自動部署網站；改了 `firestore.rules` 也會自動部署安全規則。日常維護（開通碼、Firebase、資料更新、疑難排解）見 [`docs/OPERATIONS.md`](docs/OPERATIONS.md)。

## 聲明

本網站的分析、評分、型態辨識與勝率都是依規則自動計算的結果，**不構成投資建議**。模擬盤的盤中走勢是依開高低收推算的模擬走勢，不是真實的盤中行情。
